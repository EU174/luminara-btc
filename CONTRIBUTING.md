# Contributing

Thank you for your interest in Luminara BTC.

The repository is currently in publication preflight. Executable contributions are not yet being
accepted because source provenance, licenses, architecture, and security boundaries are still under
review.

When contribution gates open, changes will use:

- one reviewable outcome per issue and pull request;
- focused tests and reproducible evidence;
- privacy and threat-impact notes for sensitive changes;
- no secrets, personal data, wallet proofs, or production details;
- respectful international collaboration and locally reviewed regional guidance.

Do not open public security reports. Follow [SECURITY.md](SECURITY.md).
