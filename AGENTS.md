# Luminara agent router

This repository uses distributed, repository-native instructions for AI-assisted work.

Before changing anything:

1. Read [`docs/ai/README.md`](docs/ai/README.md).
2. Read the `CONTEXT.md` nearest to every file you will touch.
3. Read the canonical documents linked for that scope.
4. Inspect `git status` and preserve unrelated user changes.

Permanent rules belong in `docs/ai/` or a scoped `CONTEXT.md`. Current work and status belong in GitHub Issues/Project. Temporary handoff packages belong in `deliverables/` and are not architectural authority.

When a task produces a repeatable, verified engineering practice or exposes a material regression, follow the [AI knowledge loop](docs/ai/KNOWLEDGE-LOOP.md). Record only durable evidence; do not promote unverified hypotheses or task chatter into repository policy.

Never put secrets, tokens, private keys, database URLs, or raw personal identifiers in repository documentation.
